# AirAPI report presentation lessons

## Exact ticket heading and three-line limit

Human-confirmed 2026-10-22 during SS-6409: report heading must contain the exact ticket key plus the exact task name from the ticket. Do not substitute a shortened description or a QA scope title. Keep the complete heading visible within three lines maximum by adjusting layout and typography; do not truncate, hide or ellipsize words. Verify wrapping at desktop and narrow widths. Apply to future QA dispatch reports using the shared template.
